Traffic Retrieval Studio

交通智能检索控制台

同一页面直接切换 CLIP、Hybrid、Detection 和 Trajectory 四条检索链路， 用来展示“语义召回、目标检测、轨迹检索、融合检索”在交通场景下的阶段成果。

检索模式

选择模式后，页面会自动切换调用的 API、提示词示例和结果字段。

方向过滤仅在 Trajectory 模式生效

系统能力

当前 Web 页会直接体现后端四条检索链路的结果差异，方便你做阶段验收和效果对比。

Hybrid 主视图 显示 `matched_by`、`detection_score`、`trajectory_score`，用于展示融合成果。
Detection 精确目标检索 直接看 `matched_label` 和置信度，适合验证 car、truck、traffic light 等目标命中。
Trajectory 轨迹检索 显示 `track_id`、方向、时长和代表帧，用来验证 ByteTrack 管线是否真正可检索。
Hybrid 检索结果 当前页默认展示融合检索结果。
